# 1.4 Course: identify the pain point to solve

## Overview

A companion prompt from Course Marketing by Yao Jingang, in the positioning section. Prepare: Course idea, audience profile, a specific target learner. Expected output: Action journey, pain-point matrix, course focus. See the [usage guide](../../../references/course-marketing-guide.en.md).

## Prompt

```text
Role:
You are a user experience researcher and education product manager with expertise in the pain-point positioning table and the specific target-person method. Guide me through a detailed analysis of a target learner to identify the core pain point my course should address.

Task:
Guide me step by step. My information:
- Course idea: {Example: a public-speaking course for programmers}
- Abstract audience profile: {Example: programmers aged 25-35 with strong technical skills and weaker communication skills}
- Specific target person: {Example: my friend Awei, a senior backend engineer who gets nervous during technical talks and presents dry content, leaving the audience confused}

Complete these tasks:
1. Build an action journey for Awei from receiving a speaking assignment to completing the talk.
2. Analyze pain points at each step using five dimensions: outcome, price, image, reliability, and entry barrier. Identify the biggest obstacle.
3. Diagnose the most urgent core pain point in one sentence.
4. Suggest a course positioning or teaching focus that directly addresses it.

Format:
### 1. Target person's action journey
[Clear steps]

### 2. Pain-point positioning analysis
[Step-by-step analysis using all five dimensions]

### 3. Core pain-point diagnosis
[One sentence identifying the key pain point]

### 4. Pain-relief course suggestion
[A specific product direction that addresses the pain point]
```

# 2.2 大纲：如何让你的大纲说人话

## 简介

《课程营销学》设计篇配套提示词。准备课程主题、学员画像、核心痛点、专业知识点列表，生成知识点翻译与模块化大纲。使用方法见[专题指南](../../../references/course-marketing-guide.md)。

## Prompt

```text
Role（角色）：
你是一位金牌课程设计师与教学法专家，你深知“知识诅咒”对教学效果的危害。你的核心能力是站在用户视角，将任何领域的专业知识点，转化为“说人话”的、有逻辑、有吸引力的课程大纲。你尤其擅长运用“点线面体”原则进行结构化设计。

Task（任务）：
我的新课程需要一个“说人话”的大纲。请你根据我提供的课程信息，完成以下两个核心任务：
1.  内容翻译：将我提供的每一个“专业知识点”，都转化为一个用户关心的“痛点问题”或“收益点”。
2.  结构重组：基于翻译后的内容，运用“分类法”或“因果法”，帮我设计一个包含3-4个模块的、逻辑清晰的完整课程大纲。

我的课程信息：
- 课程主题：{例如：PPT设计与制作}
- 目标用户画像：{例如：经常需要做汇报、写方案的职场白领}
- 用户核心痛点：{例如：做PPT费时费力，但效果总是不好，被老板批评}
- 我想讲授的专业知识点列表：
    - 知识点1：{例如：母版与版式设计}
    - 知识点2：{例如：色彩搭配原理}
    - 知识点3：{例如：信息图表化呈现}
    - 知识点4：{例如：动画效果与切换逻辑}
    - 知识点5：{例如：演讲者模式的应用}

Format（格式）：
请严格按照以下格式输出，让我看到你的思考过程和最终成果：

### 第一步：从“专业视角”到“用户视角”的内容翻译

- 母版与版式设计 -> 痛点问题：如何告别加班，10分钟搭好PPT框架？
- 色彩搭配原理 -> 痛点问题：为什么我的PPT看起来总有廉价感？
- （请继续完成所有知识点的翻译）

### 第二步：逻辑化大纲重组

模块一：效率篇 - 让你做PPT又快又好
   - 1.1 （翻译后的标题1）
   - 1.2 （翻译后的标题2）

模块二：美学篇 - 告别丑PPT，让老板眼前一亮
   - 2.1 （翻译后的标题3）
   - 2.2 （翻译后的标题4）

模块三：呈现篇 - 从“汇报”到“征服”
   - 3.1 （翻译后的标题5）
   - 3.2 （......）

（请为我构建完整的3-4个模块）
```
